# Hi, I'm Simone 👋

**Embedded systems & robotics engineer** based in Rome, Italy.
MSc in Artificial Intelligence and Robotics at Sapienza University of Rome.

I build things that sit between hardware and intelligence: rocket avionics with
custom PCBs and real-time firmware on one side, reinforcement learning for
humanoid robots on the other. Since 2023 I've been part of the
**Sapienza Rocket Team**, working on avionics design, assembly and flight
state estimation.
